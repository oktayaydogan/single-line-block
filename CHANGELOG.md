# Changelog

All notable changes to this project will be documented in this file.

## [0.0.4] - 2026-08-25

### Changed

- Expansion now prefers punctuation-based line breaks and avoids unnecessarily short trailing lines.

## [0.0.3] - 2026-08-25

### Updated

- Expansion now wraps regular single-line selections at 40 characters by default.
- Sentence splitting works when the next sentence starts with a lowercase letter.
- Added a keyboard shortcut for **Expand to Multiple Lines**.

## [0.0.2] - 2026-08-25

### New Features

- **Expand to Multiple Lines** command with sentence-aware splitting and configurable word wrapping.

## [0.0.1] - 2026-08-25

### Initial Release

- Initial release of the **Collapse to Single Line** command.
